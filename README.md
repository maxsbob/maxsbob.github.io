# maxsbob.github.io

Personal research website for publications, project pages, and accompanying blog posts.

## Structure

- `/publications/` — publication archive
- `/blog/` — research notes
- `/blog/enot/` — ENOT article
- `/projects/` — research project index
- `/projects/enot/` — stable pointer to the unchanged ENOT project page
- `/projects/future-paper/` — reserved route for future work

The site is plain HTML and CSS and is deployed through GitHub Pages.
